# 数据中心英语培训：学习软件质量评估与修订记录

评估日期：2026-08-25  
评估对象：GitHub Pages 线上版本与当前源码  
评估结论：内容专业度和练习覆盖已经达到优秀专项学习工具水平，但原线上版的学习路径、复习引导和数据解释不够成熟。本轮已优先修复影响每天使用的学习闭环。

## 二、本轮发现并已修复的问题

### 1. 打开首页后不知道今天该做什么

已新增“今日学习计划”：

- 默认每日20次学习活动；
- 显示今日完成数和进度条；
- 自动找到下一条未学习句子；
- 自动统计需要巩固的句子；
- 提供“继续学习”“巩固薄弱项”“开始测验”三个直接入口。

### 2. 首页数据可能在返回页面后不及时刷新

首页现在会在进入、窗口重新获得焦点、页面重新可见和跨标签数据变化时恢复最新学习记录，避免首页与学习记录数字不一致。

### 3. 学习记录把行为数据误称为能力

原来的“词汇掌握、发音/测验、理解能力、流利程度、学习连贯性”包含推算值，不能证明真实语言能力。现统一改为五项可解释指标：

- 课程覆盖率；
- 测验正确率；
- 已学掌握率；
- 复习活跃度；
- 7日连续性。

每项都显示计算依据，不再把练习次数直接说成“流利程度”。

### 4. 主题进度和薄弱句子不能精确进入内容

- 点击主题进度，现在进入该主题第一句；
- 点击薄弱句子，现在直接进入对应句子；
- 不再只跳到无筛选的句子浏览页。

### 5. 跟读结果容易被误解为专业发音评分

“跟读打分/AI评分”已改为“跟读匹配度/语音识别匹配”，并明确提示：结果比较识别文本与目标句是否一致，不代表专业音素或口音评分。

### 6. 线上版仍显示已经删除的“场景生成”

浏览器检查时，GitHub Pages 线上版仍是旧构建；当前源码已经只保留“文字互译”和“图片翻译”。发布本轮版本后，线上界面将与新源码一致。

## 三、已经具备且应保留的功能

- 中文输入自动翻成英文，英文输入自动翻成中文；
- 图片OCR提取中英文并自动互译；
- 翻译结果可收藏到“我的收藏”；
- 英文译文支持英音和美音按钮；
- 句子朗读优先使用预生成英式音频，并有浏览器语音后备；
- 闪卡“不认识”会进入待巩固状态并自动收藏；
- 测验结果进入学习记录和错题本；
- 学习记录能够迁移旧版本数据，并使用本地持久化保存。

## 四、尚未完成的中长期改进

这些问题不影响本轮上线，但仍是下一阶段升级重点：

1. 真正的间隔重复：当前是“待巩固队列”，还没有按1天、3天、7天等记忆间隔自动排期。
2. 发音精评：当前依赖浏览器语音识别，只能判断句子是否被正确识别；若要音素级评分，需要专门的发音评测服务或本地模型。
3. 性能：生产包中的2,600句学习数据约7.7MB，应进一步按主题拆分加载，降低手机首次进入句子页的等待时间。
4. 云同步：当前主要依赖当前设备和浏览器本地数据；更换手机或清理浏览器后，仍需要账号级云端同步方案。
5. 每日目标设置：本轮默认20次活动，后续可增加10/20/30/50自定义目标。
